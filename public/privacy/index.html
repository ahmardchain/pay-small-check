Pay Small Check

Privacy

A check stores the X handle, the verdict, short public excerpts, evidence links, and payment transaction hashes. The receipt is public at /proof.

The page does not display your wallet address. The payment transaction itself is public on Celo.

WhatsApp text you type on the coming-soon page is not uploaded. There is no WhatsApp data provider in this version.

The agent wallet pays buy. Those payments and the provider responses are used to build the verdict. Raw provider payloads are not stored in the receipt.
